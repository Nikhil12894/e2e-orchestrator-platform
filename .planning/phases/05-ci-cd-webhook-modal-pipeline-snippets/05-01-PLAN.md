<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User / DOM Input → Component State | User configures execution environment and timeout duration via modal inputs |
| Component State → Shell Script Interpolation | Dynamic parameters interpolated into bash scripts executed in CI/CD runner environments |
| Workflow Entity → React JSX Render | Untrusted workflow names and descriptions rendered in the browser DOM |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01 | Denial of Service | `frontend/src/utils/cicdSnippets.ts` (`sanitizeTimeoutSec`) | high | mitigate | Clamp `timeoutSec` strictly between 1 and 300 seconds (default 60s) to prevent client connection starvation or exceeding backend limits. |
| T-05-02 | Tampering | `frontend/src/utils/cicdSnippets.ts` (`generateCiCdBashScript`) | high | mitigate | Safely quote all bash variables (`"${BASE_URL}"`, `"${ENVIRONMENT}"`) and parameter expansions (`"${ORCHESTRATOR_URL:-...}"`) to prevent shell metacharacter injection in CI/CD runner pipelines. |
| T-05-03 | Tampering | `frontend/src/components/navbar/CiCdWebhookModal.tsx` | high | mitigate | Render workflow names safely using React JSX text nodes with truncation classes (`truncate max-w-md`) avoiding any raw HTML injection or XSS vulnerabilities. |
| T-05-SC | Tampering | npm/pip/cargo installs | high | mitigate | Zero new dependencies introduced in Phase 5. All capabilities leverage existing React, Lucide icons, Tailwind CSS, and Node 26 built-in `node:test` runner. |
</threat_model>
