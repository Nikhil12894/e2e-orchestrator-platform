## Visual Hierarchy & Focal Points

| Level | Element | Visual Treatment |
|-------|---------|------------------|
| Primary Focal Point | Execution Mode Switcher | Top-level segmented toggle button group (`bg-slate-100 dark:bg-slate-950` frame) with active tab pill in solid blue (`bg-blue-600 text-white shadow-sm font-semibold`) vs inactive (`text-slate-600 dark:text-slate-400`). Directly anchors the user's operational mental model between "Asynchronous (HTTP 202)" and "Synchronous (HTTP 200)". |
| Secondary Focal Point | Code Snippet Viewer Cards | High-contrast dark syntax containers (`bg-slate-950 border border-slate-800 rounded-xl`) featuring emerald code text (`text-emerald-400 dark:text-emerald-300 font-mono`), top header bar with card title, and top-right copy CTA button. |
| Tertiary Focal Point | Execution Parameter Controls | Configuration row beneath the mode switcher containing Target Execution Environment dropdown and Synchronous Timeout stepper (`timeoutSec`, clamped 1s–300s). |
| Contextual Guidance | Mode Information Banner | Dynamic informational alert box (`bg-blue-50 dark:bg-blue-950/30 border border-blue-200 dark:border-blue-900/50`) explaining whether the trigger blocks on virtual threads or returns immediate 202 with polling requirements. |

**Accessibility & Fallbacks:**
- Dismiss button (`<X />`) carries explicit `aria-label="Close CI/CD Webhook Modal"` and keyboard ESC listener.
- All code copy triggers include visible label text ("Copy Command", "Copy Script") alongside icons, and announce transient "Copied!" status via `aria-live="polite"`.

## Typography

Constrained typographic hierarchy (strictly 4 sizes, strictly 2 weights):

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Caption / Detail | 11px | 400 | 1.4 |
| Body / Code / Input | 12px | 400 | 1.5 |
| Label / Section Header | 14px | 600 | 1.3 |
| Modal Title | 16px | 600 | 1.2 |

Typographic scale details:
- **Modal Title (16px, weight 600, line-height 1.2):** Dialog heading `"CI/CD Webhook & Pipeline Integration"`.
- **Label / Section Header (14px, weight 600, line-height 1.3):** Card subsection headers, environment selector labels, tab labels.
- **Body / Code / Input (12px, weight 400, line-height 1.5):** Monospace cURL commands, bash pipeline code, dropdown option values, numeric timeout input.
- **Caption / Detail (11px, weight 400, line-height 1.4):** Modal subtitle, helper hints, parameter descriptions, HTTP status badge explanations.

## Color

60/30/10 Palette Contract:

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0f172a` (dark: `slate-900`) / `#ffffff` (light: `white`) | Modal surface, background canvas, backdrop underlay |
| Secondary (30%) | `#1e293b` (dark: `slate-800`) / `#f1f5f9` (light: `slate-100`) & `#020617` (`slate-950`) | Card containers, border dividers, code block background (`#020617`), input backgrounds |
| Accent (10%) | `#3b82f6` (`blue-500` / `blue-600`) | Enumerable list of designated interactive elements (see below) |
| Destructive | `#f43f5e` (`rose-500`) | Error status badge, HTTP 504 Gateway Timeout alert border and icon |

**Accent reserved for (explicit exhaustive list — never "all interactive elements"):**
1. Active execution mode switcher pill (`bg-blue-600 text-white`)
2. Active snippet tab indicator underline (`border-blue-500 text-blue-600 dark:text-blue-400`)
3. Code snippet copy button hover state and focus outline (`hover:bg-blue-600/30 focus:ring-2 focus:ring-blue-500`)
4. Target environment and timeout input focus borders (`focus:border-blue-500`)
5. Modal header terminal icon container background (`bg-blue-600/10 text-blue-600 dark:text-blue-400 border-blue-500/20`)

**Semantic Auxiliary Colors (justified for state feedback):**
- Success / Copied confirmation: `#10b981` (`emerald-500`) — Temporary "Copied!" checkmark feedback badge, syntax highlighted URLs in code previews.
- Warning / Timeout notification: `#f59e0b` (`amber-500`) — Informational notice regarding 504 timeout continuation in background.

## UI Considerations

Applicable state considerations resolved: 8 covered, 0 backstop, 0 unresolved.

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | Modal dialog shell | ✅ covered | When `workflow` is unselected or missing, dialog renders the documented empty state copy in `## Copywriting Contract` rather than broken template strings. |
| loading | Copy action buttons | ✅ covered | On click, button label transitions immediately from "Copy Command" to "Copied!" with `<Check className="text-emerald-400" />` for 2000ms before restoring. |
| error | Clipboard write handler | ✅ covered | If `navigator.clipboard.writeText()` rejects (e.g. insecure HTTP context or permission denial), catch handler falls back to textarea selection and displays error state copy from `## Copywriting Contract`. |
| populated | Code cards & parameter controls | ✅ covered | Standard populated view displays the selected environment, timeout input, cURL trigger snippet, polling command, report URL format, and full bash pipeline script. |
| partial | Missing environment configuration | ✅ covered | If `currentEnvironment` prop is undefined, modal safely defaults to `"default"` and populates snippet with `{ "triggerType": "WEBHOOK", "environment": "default", "initialVariables": {} }`. |
| overflow | Modal body and code blocks | ✅ covered | Modal container enforces `max-h-[85vh]` with `overflow-y-auto` vertical scrolling; code snippets enforce `max-h-[320px]` with `overflow-x-auto` horizontal scrolling and custom scrollbars. |
| zero-one-many | Mode switcher & tab list | ✅ covered | Exactly 2 execution modes (`Asynchronous` vs `Synchronous`) and 2 top tabs (`cURL Commands` vs `CI/CD Pipeline Script`) rendered with clear counts and active visual states. |
| long-text | Workflow name in header | ✅ covered | Workflow name rendered within `<span className="truncate max-w-md inline-block align-bottom font-medium">` preventing header layout distortion when workflow names exceed 50 characters. |
