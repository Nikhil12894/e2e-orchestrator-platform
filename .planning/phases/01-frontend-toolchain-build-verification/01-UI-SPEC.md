## Visual Hierarchy & Anchors

| Element | Level | Description |
|---------|-------|-------------|
| Flow Canvas (`FlowCanvas`) | Primary Anchor (Focal Point) | Interactive visual graph editor with dot grid background, custom step nodes, and directional connecting edges occupying 70%+ of the viewport. |
| Navigation Header (`Navbar`) | Secondary Anchor | Top application bar containing workflow selector dropdown, environment switcher, "Execute Workflow" action button, and execution badge. |
| Side Panels (`ApiCatalogSidebar`, `NodeConfigDrawer`) | Tertiary | Left collapsible OpenAPI endpoint catalog and right multi-tab step parameter configuration drawer. |
| Execution Console (`LiveExecutionConsole`) | Quaternary | Bottom slide-up terminal console displaying real-time step progress badges and streamed STOMP log events. |

**Accessibility & Icon Fallback:** All icon-only buttons (such as canvas zoom controls, node deletion icons, and sidebar collapse toggles) declare explicit `aria-label` attributes and tooltip text for screen reader compatibility and keyboard navigation.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, handle offsets |
| sm | 8px | Compact element spacing, badge padding, button inner gaps |
| md | 16px | Default element spacing, card padding, form field gaps |
| lg | 24px | Section padding, drawer content spacing, panel margins |
| xl | 32px | Modal dialog padding, canvas toolbar offsets |
| 2xl | 48px | Major layout section breaks, empty state container padding |
| 3xl | 64px | Page-level spacing and viewport margins |

Exceptions:
- 44px: Minimum touch and click target height for toolbar action controls
- 12px: React Flow connection handle diameter (`.react-flow__handle`) for precise edge snapping

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#f8fafc` (Light) / `#090d16` (Dark) | Canvas background, main viewport surface |
| Secondary (30%) | `#ffffff` (Light) / `#0f172a` (Dark) | Navbar, API catalog sidebar, drawer panel, execution console, modals |
| Accent (10%) | `#22c55e` (Brand Green / Emerald 500) | Primary execution trigger, passed step badges, active stream indicator |
| Destructive | `#f43f5e` (Rose 500) | Destructive actions only (Delete Workflow, remove step node, clear logs) |

Accent reserved for:
1. Primary "Execute Workflow" run button in the Navbar header
2. "Passed" / "COMPLETED" status indicator badges on canvas nodes and console items
3. Active WebSocket real-time log streaming pulse badge in the Live Execution Console
4. "Auto Layout" graph arrangement action highlight in the canvas toolbar

## UI Considerations

| Category | Element(s) | Status | Resolution / Reason |
